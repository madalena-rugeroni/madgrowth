What are Claude skills?

A Claude skill is a folder with a SKILL.md file that tells Claude how to do one job and when to do it. According to Anthropic's Agent Skills documentation, Claude keeps only each skill's name and description in mind, at roughly 100 tokens per skill, and reads the full instructions when your request matches. That means you can install a whole library and Claude only opens the skill it needs.

For business work, the difference from a prompt is consistency. A prompt depends on what you remember to paste. A skill asks the same questions, follows the same method and produces the same document every time you run it.

Which Claude skills does a business need?

A business needs skills for the decisions that are expensive to get wrong: whether to build it, who the customer is, how you're positioned, what you sell, what you charge and how you get the first customers. These are the playbooks in The Stack, each installed as a Claude skill, grouped in the order most people run them.

How are these playbooks different from a folder of prompts?

They work as one system. A setup step classifies your business once, writes it to a context file and every other playbook reads it. Later playbooks also read what earlier ones produced, so pricing knows your ICP and the landing page knows your messaging.

  • A playbook per business model. A fractional CMO pricing a retainer and a SaaS founder pricing a plan need different methods. Each playbook loads the one for your model.
  • Questions before answers. Each playbook asks for what's missing before it writes, so the output is about your business and not a plausible guess.
  • A document at the end. An ICP, an offer, a price, a launch calendar. Files you keep and edit.

How do you install Claude skills?

WhereHow to installHow to run
Claude CodePut each skill folder in ~/.claude/skills/ for all projects, or .claude/skills/ in one projectAsk naturally, or type /skill-name
Claude appTurn on code execution in Settings, then upload each skill as a zip under Customize > Skills and switch it onAsk naturally. Claude picks the skill that matches

Skills don't sync between Claude Code and the app, so install them wherever you work. Sources: the Claude Code skills docs and the Claude help center. If you'd like to write your own, read how to create a Claude skill, with a working SKILL.md example.

Are third-party Claude skills safe?

Only install skills from sources you trust, and read the files first. Anthropic's documentation warns that a skill can direct Claude to run tools or code in ways that don't match its stated purpose. The Madgrowth playbooks are Markdown instructions and reference files, with no scripts and nothing that fetches content from the internet, so you can read every line before you install them.

Questions people ask

What are Claude skills?

Claude skills are folders of instructions, and optionally reference files and scripts, that Claude loads when a request matches the skill's description. They let Claude follow the same method every time for a specific job, like writing positioning or pricing an offer, without pasting a prompt.

Are Claude skills free to use?

The Claude help center lists skills as available on Free, Pro, Max, Team and Enterprise plans, with code execution turned on. Some skills are free to download and others are sold, like The Stack. The free Expertise Audit comes by email with the Madgrowth Builder Diagnostic.

What are the best Claude skills for business?

The best ones produce a finished document and follow a named method: positioning, pricing, an offer, a launch plan. Look for skills that ask for your inputs before writing, adapt to your business model and end with a fixed output template.

Do Claude skills work in Claude Code and the Claude app?

Yes. In Claude Code, skills are folders in ~/.claude/skills/ or a project's .claude/skills/. In the Claude app, you upload a zip under Customize > Skills. Skills don't sync between the two, so install them in each place you use them.
