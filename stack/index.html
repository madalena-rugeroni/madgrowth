FAQ

Questions, answered

Is 399€ a one-time price or a subscription?

One-time. You pay 399€ once, you keep all fifteen agents, and updates are free.

What do I need to run it?

Claude, in the app or Claude Code. Each agent installs as a Claude skill. You add them once and run them in your own account, so your business details stay with you.

How is this different from a set of prompts?

Each agent is a full workflow with its own questions, a version for each business model and an output template. They share one context file, so later agents use what earlier ones produced.

What if my business doesn't fit one model neatly?

The setup step picks the closest model and notes the hybrid, for example services with a digital product on the side. Each agent uses the main model and flags where the second one changes the advice.

What if I want help using it?
