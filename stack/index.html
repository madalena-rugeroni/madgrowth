FAQ

Questions, answered

What do I need to run it?

Claude, in the app or Claude Code. You add the skills once and run them in your own account, so your business details stay with you.

How is this different from a set of prompts?

Each skill is a full workflow with its own questions, a playbook for each business model and an output template. The skills share one context file, so later skills use what earlier ones produced.

Do I have to run the skills in order?

No. Run the setup skill first, then start wherever the pressure is. There's a recommended sequence, and you're free to skip around.

What if my business doesn't fit one model neatly?

The setup skill picks the closest model and notes the hybrid, for example services with a digital product on the side. Skills use the main playbook and flag where the second model changes the advice.

What if I want help using it?
